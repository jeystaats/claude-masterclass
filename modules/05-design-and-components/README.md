# Module 05: Design & Components

## What you'll learn

You don't need to be a designer to ship beautiful products with Claude Code. This module teaches you how to extract a visual direction from references you love, set up a design system Claude will consistently apply, build a component library, and make your UI feel polished and intentional — not like it was generated by an AI.

## Lessons

| # | Lesson | Type | Time |
|---|--------|------|------|
| 1 | Design Inspiration & Visual DNA | text | 15 min |
| 2 | Design System Setup | exercise | 18 min |
| 3 | Component Library | exercise | 25 min |
| 4 | Responsive Layouts | text | 15 min |
| 5 | Animations & Interactions | text | 20 min |
| 6 | Visual Polish & The Magazine Test | exercise | 20 min |

## By the end of this module

- You have a design system with tokens, typography, and a component library that Claude applies consistently
- Your app passes the Magazine Test: it looks intentional, not default
