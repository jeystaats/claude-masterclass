# Module 01: Getting Started

## What you'll learn

In this module you set up your development environment and get comfortable talking to Claude Code. By the end you'll have a working terminal setup, Claude Code installed, and have completed your first real AI-assisted coding session. This is the foundation everything else builds on.

## Lessons

| # | Lesson | Type | Time |
|---|--------|------|------|
| 1 | Terminal Basics | text | 15 min |
| 2 | Setup & Installation | exercise | 10 min |
| 3 | AI Fundamentals | text | 15 min |
| 4 | Choosing Your Project Idea | text | 8 min |
| 5 | Your First Conversation | text | 20 min |

## By the end of this module

- You have Claude Code installed, authenticated, and working in your terminal
- You've had your first real conversation with Claude about the project you'll build during this course
