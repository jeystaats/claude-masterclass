# Module 03: Meet Your AI Team

## What you'll learn

Agents are the step-change in what Claude Code can do. In this module you'll learn what agents actually are under the hood, how to build and configure them, and how to wire them up to external tools via MCP. By the end you'll be running specialist agents in parallel and automating multi-step workflows.

## Lessons

| # | Lesson | Type | Time |
|---|--------|------|------|
| 1 | What Are Agents? | text | 15 min |
| 2 | Building Custom Agents | exercise | 25 min |
| 3 | Skills, Hooks & MCP | text | 20 min |
| 4 | Connecting Your Tools | exercise | 25 min |
| 5 | Spawning Specialist Agents | exercise | 20 min |
| 6 | Automation Pipelines | exercise | 20 min |

## By the end of this module

- You can build, configure, and spawn custom agents with the right tools and instructions
- You have at least one automation pipeline running that replaces a repetitive manual task
