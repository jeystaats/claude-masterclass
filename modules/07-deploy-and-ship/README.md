# Module 07: Deploy & Ship

## What you'll learn

Shipping is a skill. This module covers everything from setting up environment variables securely to getting your app live on a custom domain with monitoring in place. You'll also run through the full launch checklist so nothing breaks on day one.

## Lessons

| # | Lesson | Type | Time |
|---|--------|------|------|
| 1 | Environment Setup | text | 12 min |
| 2 | Deploying to Vercel | exercise | 15 min |
| 3 | Domain & DNS | text | 10 min |
| 4 | Monitoring & Analytics | text | 15 min |
| 5 | Launch Checklist | text | 12 min |

## By the end of this module

- Your app is live on a custom domain with a CI/CD pipeline, environment variables set correctly, and basic monitoring in place
- You've run the full launch checklist and your app is production-ready
