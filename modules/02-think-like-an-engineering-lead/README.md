# Module 02: Think Like an Engineering Lead

## What you'll learn

This module teaches you to think about AI-assisted development the way a senior engineer does — not as a coding assistant, but as a system you architect and direct. You'll learn how Claude's context window and memory work, how to write CLAUDE.md files that make Claude reliably productive, and how to manage cost and quality from the start.

- You understand how Claude processes context and why CLAUDE.md is your most important file
- You can write a structured PRD and break it into actionable tickets that Claude can work through reliably
