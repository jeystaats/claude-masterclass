# Module 06: Build Your App

## What you'll learn

This is the main event. You'll take the plan from Module 4 and the design system from Module 5 and build your actual app using agent-driven development. You'll learn how to run agents in parallel with worktrees, maintain codebase consistency across a long build, and know when you have an MVP worth shipping.

## Lessons

| # | Lesson | Type | Time |
|---|--------|------|------|
| 1 | From Plan to Code | text | 15 min |
| 2 | Agent-Driven Development | exercise | 25 min |
| 3 | Parallel Worktrees | exercise | 20 min |
| 4 | Maintaining Consistency | text | 18 min |
| 5 | Review & Iterate | exercise | 20 min |
| 6 | Shipping Your MVP | exercise | 15 min |

## By the end of this module

- You have a working, deployed MVP of the app you planned in Module 4
- You can run parallel agent workflows and keep your codebase consistent through a full feature build
