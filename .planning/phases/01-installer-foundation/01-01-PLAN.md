  <action>
Create install.sh at the project root. The script must work on bash 3.2 (macOS default) — NO associative arrays (declare -A), NO bash 4+ features.

Structure the script with these sections in order:

1. **Shebang and safety flags:**
   ```
   #!/bin/bash
   set -e
   set -u
   ```

2. **Configuration variables:**
   - `STARTER_DEST="$HOME/Documents/claude-mastery-starter"`
   - `REPO_URL="https://github.com/jeystaats/claude-masterclass.git"` (the actual repo)
   - `NVM_VERSION="v0.40.3"` (pinned for reproducibility)

3. **Logging functions:** `log_info`, `log_skip`, `log_done`, `log_error` (to stderr), `log_warn` — use bracketed prefixes like `[info]`, `[skip]`, etc.

4. **Utility functions:**
   - `command_exists()` using `command -v "$1" >/dev/null 2>&1`
   - `detect_os()` setting `OS` (Darwin/Linux) and `ARCH` (arm64/x86_64) and `BREW_PREFIX` (/opt/homebrew for arm64, /usr/local for Intel, empty for Linux)

5. **Install functions (each with idempotency guard):**

   a. `install_homebrew()` — macOS only. Check `command_exists brew`. If missing, install via official curl command. After install, run `eval "$($BREW_PREFIX/bin/brew shellenv)"` to get brew on PATH immediately. On Linux, skip with info message (use apt).

   b. `install_git()` — Check `command_exists git`. On macOS: `brew install git`. On Linux: `sudo apt-get install -y git` with fallback to `sudo yum install -y git`. After Homebrew git install on macOS, verify brew's git is on PATH (not just Xcode CLT git).

   c. `install_jq()` — Check `command_exists jq`. On macOS: `brew install jq`. On Linux: `sudo apt-get install -y jq` with yum fallback. jq is needed for settings.json merge in Plan 03.

   d. `install_nvm_and_node()` — Check if nvm function exists (NOT `command_exists` — nvm is a shell function). If missing: install via `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/$NVM_VERSION/install.sh | bash`. After install, explicitly source nvm:
      ```
      export NVM_DIR="$HOME/.nvm"
      [ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
      ```
      Then run `nvm install --lts && nvm use --lts && nvm alias default "lts/*"`.
      If nvm already exists, just source it and verify node is available.

   e. `install_pnpm()` — Check `command_exists pnpm`. If missing: `curl -fsSL https://get.pnpm.io/install.sh | sh -`. After install, export `PNPM_HOME="$HOME/.local/share/pnpm"` and add to PATH for current session.

   f. `install_claude_code()` — Check `command_exists claude`. If missing: `curl -fsSL https://claude.ai/install.sh | bash`. Do NOT attempt authentication. Log a clear message: "NEXT STEP: Run 'claude' and follow the browser prompts to authenticate."

6. **Clone function:**
   - `clone_starter_kit()` — Check `[ -d "$STARTER_DEST/.git" ]`. If exists, skip. Otherwise `git clone "$REPO_URL" "$STARTER_DEST"`.

7. **Main function:**
   ```
   main() {
     echo ""
     echo "=================================="
     echo "  Claude Code Mastery — Installer"
     echo "=================================="
     echo ""

     detect_os

     # Exit on unsupported OS
     if [ "$OS" != "Darwin" ] && [ "$OS" != "Linux" ]; then
       log_error "Unsupported OS: $OS"
       log_info  "Windows users: Install WSL2, then re-run this script inside WSL."
       log_info  "See: https://learn.microsoft.com/en-us/windows/wsl/install"
       exit 1
     fi

     install_homebrew
     install_git
     install_jq
     install_nvm_and_node
     install_pnpm
     install_claude_code
     clone_starter_kit
     # backup_and_merge will be added by Plan 03

     echo ""
     echo "=================================="
     echo "  Installation complete!"
     echo "=================================="
     echo ""
     log_info "Next steps:"
     log_info "  1. Run 'claude' to authenticate via browser"
     log_info "  2. cd $STARTER_DEST"
     log_info "  3. pnpm install"
     log_info "  4. pnpm dev"
     echo ""
   }

   main "$@"
   ```

Make the file executable: the plan executor should run `chmod +x install.sh` after creating it.

IMPORTANT constraints from research:
- macOS bash 3.2: NO `declare -A`, NO `${var,,}` lowercase, NO `[[ ]]` where `[ ]` suffices (though `[[ ]]` does work in bash 3.2, prefer POSIX `[ ]` for clarity)
- After Homebrew install, MUST eval brew shellenv immediately
- After nvm install, MUST source nvm.sh immediately
- After pnpm install, MUST export PNPM_HOME to PATH
- Claude Code auth CANNOT be scripted — end with manual instructions
