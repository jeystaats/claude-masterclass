**Module listing function** (dynamic, reads README.md first line for title):
```bash
list_modules() {
  echo ""
  echo "  Claude Code Mastery — Module Selector"
  echo "  ────────────────────────────────────"
  echo ""
  local i=0
  for dir in "$MODULES_DIR"/[0-9][0-9]-*/; do
    [ -d "$dir" ] || continue
    i=$((i + 1))
    name=$(head -1 "$dir/README.md" 2>/dev/null | sed 's/^# //')
    printf "  %d. %s\n" "$i" "$name"
  done
  echo ""
}
```

**Progressive skill/agent disclosure** — two `case` functions, one for skills, one for agents. Use the EXACT mapping from research (SESS-03 requirement):

**`write_session_context()` function** — accepts `module_num`, `module_dir`, `module_title`:
- `mkdir -p "$module_dir/.claude"`
- Write to `"$module_dir/.claude/session.md"` using a heredoc with `cat > "$session_file" << 'HEREDOC'` — but since variable expansion IS needed inside, use `cat > "$session_file" << HEREDOC` (unquoted delimiter)
- Template content (write exactly this structure):
  ```
  <!-- SESSION: written by start.sh — do not edit manually -->
  <!-- Module: ${module_num} | Started: $(date "+%Y-%m-%d %H:%M") -->

  ## Your Session Context

  You are helping a student working on **Module ${module_num}: ${module_title}**.

  **Working directory:** $(basename "$module_dir")/

  ## Skills available this module

  $(get_skills_for_module "$module_num")

  ## Agents available this module

  $(get_agents_for_module "$module_num")
  ```
- Call `log_done "Session context written to $(basename "$module_dir")/.claude/session.md"`

**`ensure_session_import()` function** — accepts `module_dir`:
- `local claude_md="$module_dir/.claude/CLAUDE.md"`
- `mkdir -p "$module_dir/.claude"`
- If CLAUDE.md does NOT exist: `echo "@session.md" > "$claude_md"` + `log_done "Created .claude/CLAUDE.md"`
- If CLAUDE.md exists but does NOT contain `@session.md`: append `echo "" >> "$claude_md"` then `echo "@session.md" >> "$claude_md"` + `log_done "Added @session.md import"`
- If CLAUDE.md exists AND contains `@session.md`: `log_skip "@session.md already imported"`
- Use `grep -q "@session.md" "$claude_md"` for the check (POSIX, bash 3.2 safe)

**Main execution block:**

```bash
# --- Argument handling ---
if [ $# -ge 1 ]; then
  MODULE_NUM="$1"
else
  list_modules
  printf "  Module [1-9]: "
  read -r MODULE_NUM
fi

# --- Validate input is a digit 1-9 ---
case "$MODULE_NUM" in
  [1-9]) ;;
  *)
    log_error "Invalid module number: $MODULE_NUM. Enter a number 1-9."
    exit 1
    ;;
esac

# --- Resolve module directory via zero-padded glob ---
NUM_PADDED=$(printf '%02d' "$MODULE_NUM")
MODULE_DIR=$(ls -d "$MODULES_DIR/${NUM_PADDED}-"* 2>/dev/null | head -1)

if [ -z "$MODULE_DIR" ]; then
  log_error "Module $MODULE_NUM not found in $MODULES_DIR"
  exit 1
fi

# --- Extract module title from README.md ---
MODULE_TITLE=$(head -1 "$MODULE_DIR/README.md" 2>/dev/null | sed 's/^# //')
if [ -z "$MODULE_TITLE" ]; then
  MODULE_TITLE="Module $MODULE_NUM"
fi

# --- Write session context ---
log_info "Preparing session for: $MODULE_TITLE"
write_session_context "$MODULE_NUM" "$MODULE_DIR" "$MODULE_TITLE"
ensure_session_import "$MODULE_DIR"

# --- Launch Claude Code ---
log_info "Launching Claude Code in modules/${NUM_PADDED}-*/ ..."
echo ""
cd "$MODULE_DIR" && exec claude
```
