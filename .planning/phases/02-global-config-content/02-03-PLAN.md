Create the `global-config/hooks/` directory and write three hook scripts. ALL hooks follow this exact pattern:

```bash
#!/bin/bash
# lah-check-{name}.sh
# Teaches: {what it teaches}
# Event: PostToolUse on Edit|Write
# Exit 0 = clean (silent), Exit 2 = issues found (Claude sees feedback)

INPUT=$(cat)   # ALWAYS first — consume stdin JSON
FILE_PATH=$(echo "$INPUT" | jq -r '.tool_input.file_path // empty')

# Only check relevant files
if [[ "$FILE_PATH" != *.{ext} ]]; then
  exit 0
fi

# Skip generated/vendor files
if [[ "$FILE_PATH" == *node_modules* ]] || [[ "$FILE_PATH" == *.d.ts ]]; then
  exit 0
fi

if [ ! -f "$FILE_PATH" ]; then
  exit 0
fi

ISSUES=""

# Check 1: ...
# Check 2: ...

if [ -n "$ISSUES" ]; then
  echo "{Hook name} — $(basename "$FILE_PATH"):${ISSUES}" >&2
  echo "" >&2
  echo "Fix these issues." >&2
  exit 2
fi

exit 0
```

**Hook-specific checks:**

**1. lah-check-typescript.sh** (checks .ts and .tsx files):
- `any` type usage: grep for `: any`, `<any>`, `as any` — suggest `unknown` + type guards or proper interface
- `@ts-ignore` / `@ts-expect-error`: grep for both — suggest fixing the underlying type issue
- `console.log` left in code: grep for `console.log` (not console.error/warn) — suggest removing debug logs

**2. lah-check-react.sh** (checks .tsx files only):
- Unnecessary `"use client"`: check if file imports from react (useState, useEffect, etc.) — if not, the directive is unnecessary
- `useEffect` with empty deps array for data fetching: grep for `useEffect.*\[\]` near `fetch` — suggest React Server Components or TanStack Query
- Direct DOM manipulation: grep for `document.getElementById`, `document.querySelector` — suggest using refs

**3. lah-check-cn-usage.sh** (checks .tsx files only):
- Raw template literal className: grep for `` className={` `` (backtick after className=) — suggest cn() from @/lib/utils
- String concatenation in className: grep for `className={.*+` or `className={"` — suggest cn()
- Ternary without cn(): grep for `className={.*?.*:` without cn wrapping — suggest cn(condition && "class")

Each script should be 40-80 lines. Use `grep -c` for counting occurrences. Include the DETECTED/WHY IT MATTERS/HOW TO FIX format in every issue message.

Make all scripts executable: `chmod +x global-config/hooks/*.sh`

IMPORTANT: bash 3.2 compatible. `[[ ]]` is fine (supported in bash 3.2). No `declare -A`, no `mapfile`, no `readarray`.
