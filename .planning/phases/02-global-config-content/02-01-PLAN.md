**Body** with:

**Skill-specific details:**

1. **lah-explain-code**: Auto-invocable. Pattern: analogy first, ASCII diagram, step-by-step trace, one gotcha. Description triggers: "how does this work", "explain this code", "what does this do".

2. **lah-commit-message**: Manual-only (`disable-model-invocation: true`). Pattern: conventional commits (type(scope): subject). Workflow: read staged diff, determine type, write subject + body. Include the type table (feat, fix, refactor, docs, etc.) and examples of good vs bad messages.

3. **lah-plan-task**: Auto-invocable. Pattern: decompose before coding. Workflow: state the goal, list unknowns, break into 2-4 subtasks, identify the riskiest part, start there. Description triggers: "plan this", "how should I approach", "break this down".

Each file should be 40-70 lines (frontmatter + body). Keep language conversational and beginner-friendly — these are for students new to Claude Code.
