  <files>package.json, src/lib/utils.ts</files>
  <action>
    1. Open package.json. In the `"dependencies"` object (not devDependencies — cn() is used at runtime in components), add:
       ```json
       "clsx": "^2.1.1",
       "tailwind-merge": "^2.5.5"
       ```
       Insert alphabetically among existing dependencies.

    2. Create `src/lib/utils.ts` with exactly this content:
       ```typescript
       import { type ClassValue, clsx } from "clsx"
       import { twMerge } from "tailwind-merge"

       export function cn(...inputs: ClassValue[]) {
         return twMerge(clsx(inputs))
       }
       ```

    3. Run `pnpm install` from the project root to generate pnpm-lock.yaml and install the new packages.

    Do NOT add these to devDependencies. Components import cn() in production bundles.
    Do NOT create an index barrel — a single named export from utils.ts is the standard shadcn pattern.
  </action>

  </verify>
  <done>

<task type="auto">
  <name>Task 2: Replace Geist font with system font stack and update .gitignore</name>
  <files>src/app/layout.tsx, .gitignore</files>
  <action>
    1. Open `src/app/layout.tsx`. The create-next-app default imports Geist from `next/font/google` and applies it via a CSS variable. Replace the entire file with a clean layout that uses Tailwind's built-in `font-sans` (system font stack: -apple-system, BlinkMacSystemFont, Segoe UI, etc.):

       ```tsx
       import type { Metadata } from "next"
       import "./globals.css"

       export const metadata: Metadata = {
         title: "Claude Code Mastery — Starter Kit",
         description: "A starter kit for the Claude Code Mastery course",
       }

       export default function RootLayout({
         children,
       }: Readonly<{
         children: React.ReactNode
       }>) {
         return (
           <html lang="en">
             <body className="font-sans antialiased">
               {children}
             </body>
           </html>
         )
       }
       ```

       Rationale: Geist requires a network round-trip to Google Fonts or a local font file. System fonts load instantly and are appropriate for a course scaffold where font choice is not the lesson. Students can add their own font in their own projects.
